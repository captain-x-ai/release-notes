# SQR v0.1.0 - October 22, 2026

## Improvements

### Faster Video Tracking
- Video analysis is now significantly faster — decode and 
  detection run on a background thread, appearance matching 
  is batched into a single matrix operation, and GTA-Link 
  merges use incremental state with one GPU matmul per merge.
- Annotated video is now encoded in a single pass, using 
  hardware acceleration (NVENC) when available, falling back 
  to libx264.
- 10-minute football clips now complete inference in ~20 minutes.

### More Accurate Player Identification
- Re-acquisition now evaluates every detection and picks the 
  best match, instead of defaulting to the highest IoU — 
  resulting in higher recall and fewer ID switches.
- Appearance-only matching kicks in after long occlusions, so 
  players who disappear behind others are correctly re-identified.
- Tracker ID alone no longer proves identity — the system now 
  requires appearance confirmation, reducing false matches.

### Smarter Appearance Gallery
- The player appearance gallery now grows only from validated 
  matches, not raw tracker IDs, keeping reference images clean 
  and improving match accuracy over time.
